# Reflection: ofloveandhate_paramotopy

activity pattern: it's irregular, WoC says 902 commits from 7 authors, It was active 2011 to 2013 and then only in bursts after that. There are 11 gaps of 3 months or more and the longest is 37 months from 2017-03 to 2020-03.

gaps: this one was pretty easy to figure out. The last commits before it in Feb 2017 were wrap up stuff like fixes, gitignore cleanup, a version bump, and README changes. niemerg had already stopped in 2015 so it was one person, and they moved on to other things

recovery: it came back in stages from the same person. In 2020 the commits were mostly updating their new name in the manual and welcome screen, then a small cleanup in Oct 2022. Real work only came back in 2025 with matlab code and examples, switching the build to cmake, and fixing the old 2019 issues, plus a commit saying it's now syncing to an MPI gitlab

now: it's active, there were commits in Jan, Feb, Jul and Sept 2025 and the last one was 2025-09-30
