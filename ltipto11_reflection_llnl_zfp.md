# Reflection: llnl_zfp

acivity pattern: it rose then declined after, there were 2038 commits from 84 authors, activity went from, in 2016 to 2019, 34 commits to 487, then about 250/year through 2022, then back down to 100 a year in 2023. There are only 2 gaps of 3 months or more which are both in the first two years and the longest is 5 months from 2016-04 to 2016-08. 

gaps: The pre-gap commits are not development and are instead a bulk import on 2016-03-25 of some past tarball releases, that is LLNL opening a GitHub home for existing code. there were no issues or PRs from April to August 2016.

recovery: after a 5 month gap someone named Pedro Melgueira made an issue which was then solved and that revived the project acivity after the gap 

now: it's active still and the last commit was on 2026-09, recent work is mostly Dependabot bumps and Windows/MinGW/Python 3.12 build fixes, not abandoned
