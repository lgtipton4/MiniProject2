# Reflection: qiskit_openqasm

activity pattern: there were 2033 commits from 158 authors, it had 132 commits at the start in 2017, went down to 53 in 2018 and 13 in 2019, then jumped up to 787 in 2021 with OpenQASM 3 and has stayed around 160-200 a year since. There is only 1 gap of 3 months or more which is 3 months from 2019-04 to 2019-06.

gaps: this one was kind of hard to figure out because in WoC the months around the gap look active, but most of those are auto generated PR merge commits for old PRs, not real work. The only real commits before the gap were README edits and I checked them, it was just renaming "Quantum Experience" to "IBM Q Experience" so it wasn't being archived. The spec for OpenQASM 2 was basically frozen and IBM was doing its work in Qiskit Terra instead.

recovery: it recovered mostly with new people. First there were small PRs in July and Aug 2019  then the some OpenQASM 3 work in 2020 and 2021 which moved the repo to its own openqasm org and brought in way more contributors 

now: it's active and the last commit was on 2026-07-27, recent work is mostly spec and doc edits, governance updates, and Dependabot
